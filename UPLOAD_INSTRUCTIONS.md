# Installation Instructions

## 1. Create the profile repository

Create a new public GitHub repository named exactly:

    PriyangshuBala

The spelling and capitalization must match your GitHub username.

## 2. Upload these files

Place the files at these exact paths:

    README.md
    .github/workflows/snake.yml

Do not upload the enclosing PriyangshuBala_GitHub_Profile folder itself. The README must be at the repository root.

## 3. Allow the animation workflow to publish

Open the new repository and navigate to:

    Settings → Actions → General → Workflow permissions

Select:

    Read and write permissions

Save the setting.

## 4. Generate the first contribution animation

Open:

    Actions → Generate Contribution Snake → Run workflow

Wait for the workflow to finish. It will create an output branch containing the animated SVG files. The contribution snake will then appear in the profile README.

## 5. Finish your GitHub profile

Add these profile details under GitHub Settings → Public profile:

- Bio: Data & Business Analyst | IIT Madras Data Science Graduate | SQL, Power BI, Python, ML & LLM Evaluation
- Website: https://myportfolio-one-self-69.vercel.app/
- LinkedIn: https://www.linkedin.com/in/priyangshu-bala-230973263
- Status: Open to Data, Business & Product Analytics roles

Customize your pinned repositories so your strongest analytics and product work appears directly below the profile README.
